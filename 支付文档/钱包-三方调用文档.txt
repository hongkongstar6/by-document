2.data 的加密方式

data里的参数：
{
    "amount": 10000, //操作金额 必须是正数 并且大于0
    "authUserId": "6666666", //对应上方的authUserId
    "callbackUrl": "callbackUrl", //上分回调地址
    "merchantOrder": "merchantOrder", //上分订单号
    "optType": 1, //操作类型 上分默认为1 2为下分
    "optUserId": "8888888",  //玩家在钱包注册的tgid
    "sign": "aeab62ef25936497abece865df754fc0"  //签名
}

3.sign 签名方法 
    string param = authUserId + merchantOrder + amount+optUserId+optType+callbackUrl
	 md5(param+authUserIdToken) //authUserIdToken 对应上面的authUserIdToken
    md5 之后就是对应的sign
	
	
4.data参数设置完后,对data参数的内容进行加密
	使用AES加密方式
	运算模式：ECB
	填充模式：PKCS7

5.输出格式: Base64 UrlSafe
	data参数转成json的字符串之后，使用AES加密,使用appkey 的密钥进行加密后得到 data
	vWf56GyYGzKjkArWw0JlQgCZDyEBPRpLm/j+9pFpNvnzcW15Rgf3rQmdO90Ti7RAJLbaaOwzu6QOOq9pH6V6YR/IGdp0UBjuq58Lfdw9cclGo1XIWfSbJPhw26PPgL/KEJm0erq+bb8KyKiRXHC6uHo+yZoShZNIcUQ8FcnnjJMfjl8dPDY0TZZ6GY0AkqAiPANlxwerRGr5lXZ1YQSkprOV4cPdBTOjxZ9mNnyYAII=


6.响应参数：

{
    "status": 0, //状态 0为成功 ，其余为失败
    "message": "成功",
    "data": "" //具体得响应参数
}
