1. payLink  充值创建支付链接
    url : /payLink
    参数
        unique_id : 可选(唯一编号,防止重复下单)
        name : 显示信息 可选
        amount : 金额
        return_url : 返回链接
        coin : 货币类型(USDT,TRX)
	callback_url : 可选(单独订单回调地址)
	status : 默认为0
    响应
        data[]
            order_id 订单号
            pay_url 支付链接

3.censorUserByTG 检查用户是否存在
    url : /censorUserByTG
    参数
        telegramID : telegramID
    响应
        data[]
            telegramID : 传入的ID
            exist : 布尔值 存在(true) 不存在(false)
