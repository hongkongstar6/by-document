2.上分接口：
接口： /openapi/scoreUp
传入参数：上面通用参数；加下面接口参数：
amount Integer 上分金额，分为单位；
返回如下：
{"code":0,"msg":"成功","data":null,"success":true,"dataJsonObject":null}
code： int 类型，0成功，其他都是失败；
失败时，可通过 msg 获取失败信息；

3.下分接口:
接口： /openapi/scoreDown
传入参数：上面通用参数；加下面接口参数：
amount Integer 下分金额，分为单位；
当 amount 不传或者传入0时，代表下分全部余额
返回如下：
{
    "code": 0,
    "msg": "成功",
    "data": {
        "amount": 1000
    },
    "success": true,
    "dataJsonObject": {
        "amount": 1000
    }
}
code： int 类型，0成功，其他都是失败；
成功时，从data对象中获取 amount 字段，即下分金额，分为单位；
失败时，可通过 msg 获取失败信息；
