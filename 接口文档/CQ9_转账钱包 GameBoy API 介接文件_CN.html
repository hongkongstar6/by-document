API 規範

1. 每次使用API必定會回傳 200 狀態碼，如有其他狀態碼則表示服務不通，或是服務路徑有錯
2. 時間格式為 RFC3339 EX: 2002-10-02T10:00:00.123456789-04:00(請至少支援到毫秒第9位數)
3. 每個接口若有用到時區，時間時區為 UTC-4 美東時間 ※很重要
4. 每個 Player 操作前均須要到Player 登入 做Login取得usertoken， 會在取得遊戲連結使用到usertoken
5. mtcode與roundid 為自行產生的唯一代碼(不可含特殊字元)，建議可使用UUID
6. 報表類API內若有包含開始時間(starttime)與結束時間(endtime)參數,該時間皆包含在查詢範圍。
例如：
i. 查詢一日的資料
設定 開始時間 (starttime) 為 2017-05-15T00:00:00-04:00
設定 結束時間 (endtime) 為 2017-05-15T23:59:59.999-04:00-04:00
所查詢到的資料範圍會是當天一整天的資料。
※若使用最小單位(groupby)為hour查詢時，starttime的分鐘或秒數請設置為0確保查詢資料完整
ii. 查詢跨日資料
設定 開始時間 (starttime) 為 2017-05-14T01:00:00-04:00
設定 結束時間 (endtime) 為 2017-05-15T00:59:59.999-04:00
所查詢到的資料範圍會是跨日資料
※endtime查詢時請加上.999確保查詢資料完整

除以上報表類API外，其餘API(如交易查詢&注單查詢)皆使用整點時間進行查詢且均支援查詢一日和跨日的資料
※注意有些API限制跨日最多一日 ex.錢包歷程

7. 測試環境不需要添加白名單；正式環境需要添加白名單
8. 損益金額計算公式：

玩家損益金額(從玩家角度來計算玩家損益)：
真人視訊/牌桌類：win-rake-roomfee
老虎機/街機/魚機/彩票：win-bet

代理損益金額(從代理角度來計算代理損益)：
真人視訊/牌桌類：rake-win+roomfee
老虎機/街機/魚機/彩票：bet-win

9. 當API呼叫方法為GET時，URL後方使用變數意思等於URL後方直接帶入玩家名稱
舉例：若欲查詢玩家"ABC"的餘額
/gameboy/player/balance/:account與/gameboy/player/balance/ABC的查詢方法是一樣的
10. 測試環境數據保存D+3天，正式環境數據保存D+3個月，( D：拉取數據當日 )

API 使用流程圖（不使用大廳版本）

  1. 建立 Player
  2. 使用 Player 登入 取得 usertoken
  3. 使用遊戲列表取得gamecode
  4. 之後可透過gamecode及usertoken 進行 Player取得遊戲連結
  5. 結束遊戲時請使用玩家登出

PS：當使重複使用同帳號登入時，會採後踢前，將原有usertoken登出

API 使用流程圖（使用大廳版本）

  1. 建立 Player
  2. 使用 Player 登入 取得 usertoken
  3. 之後可透過usertoken 進行 Player取得遊戲大廳連結
  4. 結束遊戲時請使用玩家登出

PS：當使重複使用同帳號登入時，會採後踢前，將原有usertoken登出

後綴使用說明

獲取連結後，使用者可以自行添加後綴來啟用特定功能。以下是常見的後綴範例：

進入單桌(真人專用)

後綴 描述
&tabletype=baccarat 進入百家單桌
&tabletype=marble 進入彈珠單桌
&tabletype=pk10 進入彈珠PK10
&tabletype=sedie 進入色碟
&tabletype=sicbo 進入骰寶
&tabletype=dt 進入龍虎
&tableid=XXX 桌號
&nolobby=true 禁止從單桌進入大廳

只顯示單一真人大廳情境

後綴 描述
&only=1 只顯示百家大廳
&only=2 只顯示彈珠大廳

電子遊戲

後綴 描述
&LeaveButton=Y 開啟殘忍離開選項
&LeaveButton=N 取消殘忍離開選項
&leaveUrl={{URL}} 關閉遊戲後導向之網址
